## Features

- **Compact Window**: One small, click-through window with profit per hour, the current map's profit and timer, and the map's loot.
- **Dashboard**: One window with tabs (Overview, Session, Inventory, Prices and Strategies) for the current session, past sessions, your bag, market prices and the community's best farming strategies.
